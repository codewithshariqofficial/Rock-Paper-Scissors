# Rock Paper Scissors

An advanced, browser-based **Rock Paper Scissors** game built with pure HTML, CSS, and JavaScript. Play against a random AI opponent, track your wins/losses/draws, and persist your stats in the browser.

## ✨ Features

- 🎮 Play Rock, Paper, or Scissors against an AI opponent
- 🤖 AI makes a random move each round
- 📊 Live score tracking (Wins, Losses, Draws)
- 💾 Stats persisted in the browser using `localStorage`
- 🔄 Reset stats with a confirmation prompt
- 🎨 Glassmorphism UI with animated background blobs
- 🎬 Smooth pop animations for choices and results
- 📱 Responsive layout for mobile screens
- ⚡ No build tools or dependencies required

## 🛠️ Tech Stack

- **HTML5** – structure
- **CSS3** – styling, animations, responsive layout
- **Vanilla JavaScript (ES6)** – game logic and state
- **Google Fonts (Poppins)** – typography

## 🚀 Getting Started

No installation or build step is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/codewithshariqofficial/Rock-Paper-Scissors.git
   cd Rock-Paper-Scissors
   ```

2. Open `index.html` in any modern web browser.

## 🎯 How to Play

- Click **Rock**, **Paper**, or **Scissors** to make your move.
- The AI makes a random move.
- The result and updated stats are shown instantly.
- Click **Reset Stats** to clear all scores.
