# Rock Paper Scissors

A simple browser-based Rock Paper Scissors game built with HTML, CSS, and JavaScript. Play against an AI opponent, track your stats, and reset them anytime.

## Features

- Play Rock, Paper, or Scissors against a random AI move
- Live score tracking (Wins, Losses, Draws)
- Stats saved in browser using `localStorage`
- Reset stats button
- Responsive UI with glassmorphism design and animations

## Project Structure

```
Rock-Paper-Scissors/
├── index.html
├── styles/
│   └── main.css
└── js/
    ├── game.js
    └── stats.js
```

## How to Run

1. Clone or download the project.
2. Open `index.html` in any modern web browser.
3. No build tools or dependencies required.

## How to Play

- Click **Rock**, **Paper**, or **Scissors** to make your move.
- The AI makes a random move.
- The result and updated stats are shown instantly.
- Click **Reset Stats** to clear all scores.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- Google Fonts (Poppins)
